# CIDM 6355: Data Mining Methods

This repository contains coursework completed for CIDM 6355, Data Mining Methods, as a graduate student. The notebooks demonstrate practical data preparation, feature engineering, classification, model evaluation, cross-validation, and threshold tuning using Python.

## Projects

### Netflix Engagement Prediction

[Netflix_Engagement_Garza_Oscar.ipynb](Netflix_Engagement_Garza_Oscar.ipynb) predicts whether a viewing session will result in a full watch. The analysis compares K-nearest neighbors, decision tree, support vector machine, and neural network models using accuracy, precision, recall, F1 score, ROC-AUC, confusion matrices, and ROC curves.

### Uber Demand Classification

[Garza_Oscar_FinalProject.ipynb](Garza_Oscar_FinalProject.ipynb) uses New York City Uber pickup data to classify hours as high or low demand. The project includes exploratory analysis, preprocessing, logistic regression, cross-validation, performance interpretation, and decision-threshold tuning.
